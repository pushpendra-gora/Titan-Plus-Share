# Titan Plus Share ✈️
> **Fast • Simple • Anywhere** (Electric Blue Edition)

Titan Plus Share is a premium cross-platform file-sharing application with native Windows and Android applications, right-click Windows Explorer sharing, Android system share sheet integration, and a 3-hour self-expiring remote download server.

## ⚡ Key Capabilities

### 1. 💻 Windows Desktop Application (`Titan-Plus-Share.exe`)
- Keep `Titan-Plus-Share.exe` directly on your desktop or anywhere on your PC.
- Double-click to launch: It automatically starts the host server in the background and opens the modern Blue White Card application interface.
- No terminal or command prompt needed!

### 2. 🖱️ Windows Explorer Right-Click Share
- Right-click **ANY file or folder** on your PC and select **"Share with Titan Plus Share"**.
- Automatically launches the app with that file pre-loaded into the **"Send How?"** modal.
- To enable: Run [**`Add-To-Windows-Context-Menu.bat`**](./Add-To-Windows-Context-Menu.bat) once.

### 3. 📱 Android System Share Sheet Integration
- Tap **Share** in any app on Android (WhatsApp, Gallery, File Manager, Browser).
- Select **Titan Plus Share** from the list to send immediately.

### 4. 🔗 3-Hour Self-Expiring Download Links
- When generating remote links, files are hosted on the laptop server for **exactly 3 hours** and then automatically cleaned up.
- Includes a live countdown timer and responsive web download page for anyone accessing from a browser.

### 5. 📶 Direct LAN Transfer (Same Network)
- Zero internet required for local Wi-Fi transfers.
- Real-time speed indicator (MB/s), progress bar, and instant completion.
